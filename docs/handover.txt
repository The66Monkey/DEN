GET STARTED
1. Connect your computer or phone to your home network.
2. Open the service addresses below in your browser. Replace DOMAIN with the
   domain recorded above. Fedora Server itself does not need a desktop.
   Photos: https://photos.DOMAIN
   Files:  https://files.DOMAIN
   Media:  https://media.DOMAIN
   Git:    https://git.DOMAIN
3. Install KeePassXC on your own computer from https://keepassxc.org.
   Open den-credentials.kdbx from this folder when the installer supplies it.
   Obtain its master password separately from the installer.
   Never save the master password on this USB.
4. Use your personal application account for everyday access. Ask the installer
   to complete administrator setup before handover. DEN-generated credentials
   do not include every password created or changed inside an application.

EVERYDAY USE
Keep the server powered, its network connected, and its data and backup disks
attached. This handover USB can be safely ejected and stored somewhere private.
Automatic maintenance normally runs monthly, on the first day from 04:00
server time. Applications may be briefly unavailable while it updates or
reboots. No routine dashboard or alert checks are expected from you.
Keep irreplaceable photos and files in another independent location too:
automatic backups can fail unnoticed, even while applications still work.

PASSWORDS AND ACCESS
Keep a protected second copy of your vault and store its password separately.
If you change an application password, update your KeePass entry yourself.
DEN does not configure email password resets; contact your administrator.
Away from home, use the WireGuard VPN profile provided by the installer.
Each device needs its own profile. Never share a VPN profile or forward SSH
port 22 on your router just to access the server.

IF SOMETHING STOPS WORKING
Check that the server has power, network, and its normal disks connected.
Try again from the home network. Do not bypass browser certificate warnings.
If it still fails, contact the support person above.
An administrator can connect using the Fedora account set up at installation:
  ssh YOUR-FEDORA-USER@SERVER-ADDRESS
Then run:
  sudo den status
  sudo den check
  systemctl --failed
Do not reinstall DEN, delete its settings, or format a disk to fix an error.
DEN has no email/push alerts. These checks are for troubleshooting when you
notice a problem, not a routine task for the owner.
