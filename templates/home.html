Manage your server

From a terminal on your home network or VPN, run:

ssh YOUR-FEDORA-USER@{{LAN_IP}}

Replace YOUR-FEDORA-USER with your Fedora login. Then run sudo den status to check services or sudo den help for commands.

Documentation and updates: DEN on GitHub.

Private account and setup tools. Connect over SSH, then:

sudo grep '^NEXTCLOUD_ADMIN_PASSWORD=' /opt/den/.env
sudo den keepass-password
sudo den vpn-add DEVICE-NAME

The first command retrieves the initial Nextcloud password; the second prints the optional KeePass vault password; the third creates a private VPN profile for a new device. Treat all outputs as private.
